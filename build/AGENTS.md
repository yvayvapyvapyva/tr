# build/ — папка с минифицированной сборкой для хостинга

Это НЕ исходники. Здесь лежит готовый к публикации билд Telegram Mini App
«Сцепление — 3D модель» (тренажёр сцепления/КПП), собранный в ОДИН файл.

## Состав

| Файл          | Назначение |
|---------------|------------|
| `index.html`  | весь билд: разметка + CSS + весь JS приложения в одном `<script type="module">` |
| `version.txt` | номер версии (например `1.5`), нужен для обхода кэша Telegram WebView |

Исходники, из которых собран билд, лежат в корне репозитория:
`scep3d.html`, `carConfig.js`, `transmission.js`, `report.js`.

## Как заливать на хостинг

1. Залить `build/index.html` как `index.html` в корень сайта (Cloudflare Pages / любой статический хостинг).
2. Залить `build/version.txt` в тот же корень — без него не будет работать проверка версии.
3. Внешние зависимости подтягиваются с CDN, их заливать не нужно:
   - `https://telegram.org/js/telegram-web-app.js` (SDK Telegram)
   - `https://unpkg.com/three@0.160.0/...` (three.js + OrbitControls, через `<script type="importmap">`)
4. Заголовки из корневого файла `_headers` (Cloudflare Pages) тоже нужны: они отключают кэширование,
   иначе Telegram WebView на iOS/Android продолжит показывать старую версию. Файл лежит в корне репозитория,
   в эту папку он не скопирован.

## Правила работы с этой папкой

- **Не редактировать `index.html` вручную.** Минифицированный код нечитаемый, любые правки будут
  потеряны при следующей пересборке. Все изменения — в исходниках в корне репозитория.
- **После каждого изменения исходников папку `build/` нужно пересобрать заново**, иначе на хостинг
  уедет старый код. Сборка = esbuild: `carConfig.js` + `transmission.js` + тело `<script type="module">`
  из `scep3d.html` + `report.js` склеиваются в один модуль, минифицируются
  (`--bundle --minify --format=esm --target=es2020`), `--external:three` и
  `--external:three/addons/controls/OrbitControls.js`; CSS минифицируется отдельно.
- **При деплое обновлять `version.txt`** (например `1.5` → `1.6`). Скрипт в начале `index.html`
  сравнивает его с сохранённым в `localStorage` и перезагружает страницу, иначе WebView
  продолжит отдавать старый кэш.
- Известная деталь сборки: в `scep3d.html` есть свой `WHEEL_R = 2.32` (радиус колеса в 3D),
  а в `carConfig.js` — `WHEEL_R = 0.305` (физика, попадает в `PHYS.RWHEEL`). В исходниках это
  разные модули, после склейки — коллизия, поэтому при сборке 3D-константа переименовывается
  в `WHEEL_R3D`. Если появится новая коллизия имён верхнего уровня, разрешать так же:
  переименовывать константу в билде, исходники не трогать.
- Логика отчётов о запуске (`report.js`) встроена в билд; адрес Cloudflare Worker
  (`https://pad-report.ivan43103.workers.dev/`) и пустая `REPORT_KEY` заданы внутри кода.
  Токен бота и `REPORT_CHAT_ID` хранятся в env самого Worker (`cloudflare_worker/worker.js`),
  в этой папке секретов нет.
